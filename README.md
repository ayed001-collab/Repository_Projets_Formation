# Repository_Projets_Formation
Repository dédié à la formation dans le domaine de l’Assurance, proposant deux parcours complémentaires : une formation sur les fondamentaux de l’Assurance et un parcours expert pour approfondir les concepts, processus et enjeux métier.

## Projets

- **[apprentissage-japonais/](apprentissage-japonais/)** — 先生 Sensei, un agent web interactif pour apprendre le japonais (vocabulaire, verbes et grammaire), affiché en japonais, rōmaji et français, avec des images pour un apprentissage visuel.
